⚡ Pokemon Arena – Серверная часть

📌 О проекте
Pokemon Arena – это симулятор тренера покемонов с возможностью создавать покемонов, сражаться с ботами и дикими покемонами, повышать уровень и соревноваться в рейтинге.

Проект создан с целью обучения тестированию API-серверов. Он предоставляет полноценный REST API с документацией Swagger, позволяющий изучать методы HTTP, работу с JSON, обработку ошибок, а также логику боевой системы и управления состоянием.

Разработка велась совместно:
- Tikora0 – идея, постановка задач, тестирование, обратная связь.
- DeepSeek (AI-ассистент) – написание кода, документации, интеграция Swagger, оптимизация логики.

Технологии: Node.js, Express, JSON-база данных, Swagger (OpenAPI).

🚀 Быстрый старт (для Windows)

1. Установите Node.js
   - Скачайте и установите Node.js с официального сайта: https://nodejs.org/ (рекомендуется LTS-версия).
   - Проверьте установку, открыв командную строку (Win+R → cmd) и введя:
     node -v
     npm -v
   - Должны отобразиться версии (например, v18.x.x и 9.x.x).

2. Распакуйте архив с проектом
   - Скопируйте папку "Сервер покемоны" на диск E:\ (или любое другое место).
   - Убедитесь, что структура папок выглядит так:
     E:\Сервер покемоны\
     ├── server.js
     ├── bot.js
     ├── package.json
     ├── package-lock.json
     ├── start-server.bat
     ├── README.md
     ├── public\
     │   ├── index.html
     │   ├── avatars_mentors\
     │   └── avatars_pokemons\
     └── node_modules\ (будет создан после установки)

3. Установите зависимости
   - Откройте командную строку в папке с проектом:
     - Зажмите Shift + правый клик в пустой области папки → "Открыть окно PowerShell/командной строки здесь".
   - Выполните команду:
     npm install
   - Дождитесь завершения установки (появится папка node_modules).

4. Установите дополнительные пакеты (для Swagger)
   - В той же командной строке выполните:
     npm install swagger-jsdoc swagger-ui-express

5. Запустите сервер
   - Способ 1 (рекомендуемый): дважды кликните по файлу start-server.bat.
   - Способ 2 (ручной): откройте командную строку в папке проекта и выполните:
     node server.js

🌐 Доступ к приложению после запуска
После успешного запуска сервера в браузере будут доступны:

- http://localhost:3000 – 🎮 Клиентская часть – игровой интерфейс
- http://localhost:3000/api-docs – 📚 Swagger документация API – интерактивная документация с возможностью тестирования запросов
- http://localhost:3000/api/mentors – 📡 Пример API-запроса – список всех тренеров

💡 Совет: если вы запускаете сервер через start-server.bat, браузер автоматически откроет клиент и Swagger в разных вкладках.

🧪 Тестирование API через Swagger
1. Откройте http://localhost:3000/api-docs
2. Выберите нужный эндпоинт (например, GET /mentors)
3. Нажмите Try it out
4. Введите параметры (если требуется) и нажмите Execute
5. Внизу отобразится ответ сервера (статус, тело ответа)

🛠️ Возможные проблемы и их решение

Ошибка "Cannot find module 'express'"
→ Выполните npm install в папке проекта.

Ошибка "Cannot find module 'swagger-jsdoc'"
→ Выполните npm install swagger-jsdoc swagger-ui-express.

Порт 3000 уже занят
→ Закройте другие программы, использующие порт 3000, или измените PORT в файле server.js.

Сайт не открывается
→ Убедитесь, что сервер запущен (в командной строке видно "🚀 Сервер запущен на http://localhost:3000").

Покемоны не отображаются
→ Удалите файл db.json и перезапустите сервер – он создаст новую базу.

Swagger не открывается
→ Проверьте, установлены ли пакеты swagger-jsdoc и swagger-ui-express.

📂 Структура базы данных (db.json)
Файл db.json создаётся автоматически при первом запуске. Он содержит:
- mentors – список тренеров (игрок + 10 ботов)
- pokemons – все покемоны (ботов, игрока и дикие)
- battleLogs – история боёв
- botSpeed – скорость работы ботов (в секундах)

🔄 Обновление сервера
Если вы получили новую версию проекта:
1. Остановите сервер (Ctrl+C в окне командной строки)
2. Скопируйте новые файлы (server.js, bot.js, public/index.html и т.д.)
3. Выполните npm install для обновления зависимостей (если изменился package.json)
4. Запустите сервер заново
